# JoyOrbit development adaptation

Source changes and build recipes are mirrored under joyorbit-build. These recipes are used from the PrecisionDataHQ/joyorbit-app application checkout; their paths remain relative to that checkout. Upstream code and notices remain in this fork's history. The application repository is private during development and must be published with complete corresponding source before distribution.

Pinned versions: SuperTuxKart1.5, Pixel Wheels1.0.1, Super Tilt Bro2.6. Android native engines use isolated processes; long Back and Select+Start request a graceful exit. Physical-device/gamepad acceptance is untested. The no-network STB build removes the unclear-licensed Sagely Concerto track and substitutes Fusolis (CC BY4.0); Ozzed arrangements keep CC BY-SA3.0 attribution.
